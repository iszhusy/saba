## 一、技术栈（已确认实现）

### 后端
| 组件 | 选择 | 说明 |
|------|------|------|
| 语言 | TypeScript | 全栈统一语言 |
| 运行时 | Cloudflare Workers | Edge 部署，冷启动快 |
| 数据库 | Cloudflare D1 (SQLite) + KV | 评估结果 KV 存储，关系数据 D1 |
| LLM | Claude API (Sonnet 4) | Anthropic SDK 接入 |

### 前端
| 组件 | 选择 | 说明 |
|------|------|------|
| 框架 | React | 轻量，组件化 |
| 样式 | TailwindCSS | Utility-first，自定义设计系统 |
| 构建 | Vite | 快速 HMR |

### 基础设施
| 组件 | 选择 |
|------|------|
| 部署 | Cloudflare Workers |
| KV | Cloudflare KV |
| 数据库 | Cloudflare D1 |
| 监控 | Cloudflare Analytics |

## 三、Agent 系统核心架构

### 评估流程（三层决策）

```
用户输入
    │
    ▼
┌──────────────────────────────────────────────────────────────┐
│  Layer 1: 规则引擎 (Rule Matching)                           │
│  → 高风险关键词扫描（原始文本正则匹配）                        │
│  → 症状-规则匹配                                             │
│  → 命中高风险规则 → 直接返回，不调用 LLM（安全优先）         │
│  → 置信度：0.95+                                             │
└─────────────────────────────────┬────────────────────────────┘
                                  │
                    ┌─────────────┴─────────────┐
                    │ 未命中高风险规则          │
                    ▼                          ▼
┌──────────────────────────────────────────────────────────────┐
│  Layer 2: RAG 检索 (Knowledge Retrieval)                     │
│  → 基于症状检索 CTCAE 知识库                                 │
│  → 匹配副作用管理指南                                        │
│  → 提供循证上下文供 LLM 参考                                  │
│  → 置信度：0.90+                                             │
└─────────────────────────────────┬────────────────────────────┘
                                  │
                    ┌─────────────┴─────────────┐
                    │ LLM 可用                    │
                    ▼                            ▼
┌──────────────────────────────────────────────────────────────┐
│  Layer 3: Claude LLM (Deep Reasoning)                        │
│  → 综合规则 + RAG + 症状严重程度 + 治疗阶段上下文            │
│  → 风险等级最终判定                                          │
│  → 个性化建议生成                                            │
│  → 置信度：0.85+                                             │
│                                                              │
│  ⚠️ 降级策略：无 API Key 时，纯用规则引擎                    │
└──────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
                          最终响应
```

### 决策融合策略

| 场景 | 规则引擎 | LLM | 最终决策 |
|------|----------|-----|---------|
| 高风险规则命中 | high | 任意 | **high**（不降级） |
| 规则未命中 | low | high（置信>0.9） | **high** |
| 规则低风险 | low | high（置信>0.9） | **high** |
| 规则中风险 | medium | high（置信>0.9） | **high** |
| 无 API Key | 任意 | - | 规则引擎结果 |
| LLM 调用失败 | 任意 | error | 规则引擎结果（降级） |

```

│

    ├── ui/RiskBadge.tsx
    └── assessment/...
```
