# SABA — 一句话目标

**SABA** 是面向乳腺癌患者**副作用报告**场景的 AI-native 临床判断系统：由单一对话执行主体（Conversation Executive）驱动，在安全约束下完成分流、澄清与保守建议，**不诊断、不开药、不替医嘱**。

**成功标准**：用户只感知一个连贯助手；内部以 reasoning surface 分工；结论显式区分 provisional / conclusive / insufficient；安全以 constraint 注入 synthesis；多轮以 Episode 保持临床连续性；P0 场景由 evaluation harness 可回归验证。
